# SERASA — Keripik Pedas

Website order sederhana berbasis HTML/CSS/JS.

## Isi
- `index.html` — halaman website
- `style.css` — tampilan
- `script.js` — kalkulasi harga + order WhatsApp
- `assets/` — foto produk dan logo

## Upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, `script.js`, dan folder `assets`.
3. Masuk ke **Settings → Pages**.
4. Pilih branch utama (`main`) dan folder `/root`.
5. Simpan. GitHub akan memberikan alamat website.

Catatan: website ini tidak memakai database. Pesanan dikirim langsung ke WhatsApp admin melalui link `wa.me`.
